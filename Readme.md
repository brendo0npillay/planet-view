# 3D Planet Viewer

Planet View is an interactive 3D solar system experience built for the browser. Explore planets in real time, switch between them instantly, and learn key facts while a smooth camera orbits each world in space.

## **Features**

- Interactive 3D planets rendered in real time
- Clickable planet navigation
- Smooth animated camera orbit per planet
- High-resolution planet textures
- Realistic lighting and starfield background
- Dynamic planet descriptions

## **Technologies Used**

- JavaScript (ES Modules)
- Three.js (WebGL rendering)
- Vite (development & bundling)
- HTML5 Canvas
- CSS

## Usage

1. Open the app in a modern browser
2. Click a planet name from the list
3. Camera smoothly transitions to that planet
4. Read the planet’s description
5. Switch planets at any time to explore
